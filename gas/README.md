# 鍋淬訂單寫入 Google 試算表（Apps Script）

網站結帳送出後，會 POST 到一個 Apps Script 網頁應用程式，由它寫入試算表的「訂單」工作表。

## 一、建立試算表與腳本

1. 到 Google 試算表建立新檔案，命名為「鍋淬訂單」。
2. 選單 **擴充功能 → Apps Script**。
3. 刪除預設程式碼，把 `gas/Code.gs` 的內容整段貼上，儲存（Ctrl/Cmd+S）。
4. 若要使用密碼保護，把 `TOKEN` 改成一組自訂字串（例如隨機 24 字元），之後前端也要填同一值。

## 二、部署為網頁應用程式

1. 右上角 **部署 → 新增部署作業**。
2. 類型選 **網頁應用程式**。
3. 說明：`orders v1`；執行身分：**我**；誰可以存取：**所有人**。
4. 按 **部署**，第一次會要求授權，請允許存取試算表。
5. 複製產生的網址（格式為 `https://script.google.com/macros/s/…/exec`）。

## 三、連接網站

打開 `index.html`，找到：

```js
const ORDER_ENDPOINT = '';
const ORDER_TOKEN = '';
```

把網址填入 `ORDER_ENDPOINT`；若第一步有設定 `TOKEN`，同樣填入 `ORDER_TOKEN`。兩者都留空時，網站維持原本的「模擬訂單」展示模式。

## 四、測試

- 瀏覽器開啟部署網址，應看到 `{"ok":true,"service":"guocui-orders"}`。
- 在網站加入商品、送出結帳，試算表應新增一列，訂單編號為 `GC yyyymmdd-0001` 格式。

## 注意事項

- **價格以 `Code.gs` 內的 `PRICES` 為準**，前端金額只供顯示。調整菜單價格時，兩邊都要改。
- 網站上的隱私說明會在啟用後自動改為「訂單資料會傳送至店家後台」的版本；仍建議由法務確認文字。
- 試算表資料包含顧客姓名、電話與地址，請限制試算表的共用對象。
- 若需要新訂單通知，可在 `doPost` 中加入 `MailApp.sendEmail(...)`，但每筆都會寄信，流量大時請改用其他通知方式。
